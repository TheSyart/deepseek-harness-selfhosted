# @deepseek-ai/dsh-client-ui-shuangwen

[English](README.md) | 中文

爽文写作模式插件,面向 Web GUI:一条浏览器侧的一键快捷条,让 `shuangwen` agent preset 真正做到「无脑」。其主机侧刻意为空——写作体验由 preset 的 persona 承担,主机平面的工具行会并入每一个 agent,无论它由哪个 preset 组装。

快捷条挂载为 `conversation.input.dock` 条目,仅当当前会话运行在 `shuangwen` preset 上时渲染(preset id 从会话列表花名册记录的 `agentPreset` 读取)。两种姿态:

- **空白会话**——开书姿态显示三个开书脑洞 chip(赘婿重生 / 废柴修仙 / 末日签到)。点击把一条完整的开书指令写入草稿但不发送:第一条消息定下整本书,因此它保持可编辑,直到用户按下回车。
- **已开始的会话**——续写姿态显示三个拨盘 chip(下一章 / 加大爽度 / 来个小高潮)。点击写入指令**并提交**,下一章零输入开始。

会话被移除、回合运行中、输入处于提交中途或草稿非空时,快捷条自我隐藏——绝不覆盖进行中的输入。所有数据都走框架 hook(会话列表、会话快照、输入状态机),发送走公开的 `inputActions` 面;插件不注册自己的业务面。chip 标签在 `shuangwen` locale 命名空间下双语;写入草稿的消息文本是组件拥有的中文提示词载荷,不属于文案。

## 模型体验

经由 `shuangwen` preset 的 persona(由 `dsh-persona` 拥有)间接影响:本快捷条提交的消息是普通用户消息,与其他消息一样记录日志。

#### KV Cache 影响

点击开书 chip 只修改草稿。提交时会向对话追加一条普通用户消息；系统提示词由所选 preset 拥有，快捷条不会改写它。

## 已知限制与暂缓事项

- **默认 Web 组装未启用**——该快照包含 preset 并构建此插件，但 `dsh-web-app` 未安装或挂载它。部署必须显式组装后才会出现快捷条；构建与组件测试不代表集成已验证。
- **preset id 硬编码**——快捷条只服务内置的 `shuangwen` preset;以其他 id 本地复制的 preset 不会得到快捷条。
- **忙碌时让出舞台**——回合运行中或草稿非空时隐藏 chip,因此一章写完才会出现下一次一键续写。
- **开书脑洞集合是静态的**——三个固定脑洞;用户仍可手输任何开书指令。
