# @deepseek-ai/dsh-client-ui-settings-token-usage

[English](README.md) | 中文

浏览器设置 shell 中的紧凑 Token 用量分区。它以 order `12` 注册 id 为 `token-usage` 的 `settings.section`，并按浏览器当前 IANA 时区读取全局 Host 报告。

## 仪表盘

Lifetime 卡片显示总 token、全部输入 token、输出 token 与缓存命中率。输入等于未缓存输入、缓存读取和缓存写入之和；命中率等于缓存读取除以全部输入，分母为零时显示破折号。活跃度、趋势和模型是同一份报告上的独立视图，因此切换视图不会重新请求，也不会挤满 800 像素设置界面。

活跃度视图提供每日、每周与累计三种口径。每日和累计使用 365 天日历网格；每周按周一至周日汇总，并保留窗口首尾的不完整周。三种口径都按非零值分配五档分位强度，并使用一个可移动的键盘焦点。累计表示从当前滚动 365 天窗口起始日开始的运行总量，不是 Lifetime。

30、90、365 天趋势视图默认按精确模型路由展示。前五条路由各自成线，其余全部合并为“其他”。路由颜色在页面生命周期内保持稳定；虚实线、点型、tooltip、无障碍名称与图例开关使曲线不只依赖颜色区分。“按类型”模式改为展示未缓存输入、缓存读取、缓存写入与输出。模型视图共享所选周期，默认显示前五条路由，可以展开全部精确路由，并在 hover、焦点和辅助技术中提供输入／输出组成。

## 刷新生命周期

页面进入后立即加载，只在已挂载且可见时轮询；隐藏页面恢复可见时立即刷新。请求保持 single-flight，并可取消。后续失败会保留最后一次成功结果并标记陈旧；首次失败显示重试状态。可选间隔为 `5`、`10`、`30` 或 `60` 秒，存放在 `ui-token-usage.refreshIntervalSeconds`，默认 `30`。回环浏览器通过用户设置持久化；权限受限的远程浏览器只在当前进程保留。

## 组合

```yaml
- name: '@deepseek-ai/dsh-client-ui-settings-token-usage'
```

页面需要生成的 `tokenUsageReport` Remote，以及客户端 runtime、settings 与 locale 服务。它在设置导航中使用私有 glyph，不扩展共享图标 API。

## 模型体验

无。该包只在浏览器中渲染来自已记录用量的报告。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求。

## 已知限制与暂缓事项

- **仪表盘不估算费用或缺失用量**：它只可视化 Host 报告返回的四项提供方上报 token bucket。
- **按模型趋势只保留五条具名路由加“其他”**：模型视图保留所选周期内的每一条精确路由。
- **日历分组遵循浏览器时区**：操作系统时区变化后，下一次报告请求的日期边界也会变化。
